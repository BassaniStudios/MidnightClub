HOW TO USE
1. Open index.html in a browser.
2. To add music: edit assets/main.js and fill the TRACKS array:
   { title: "Nome", artist: "Artista", src: "assets/music/arquivo.mp3" }
3. Upload the folder to GitHub Pages or any static host.
