MIDNIGHTCLUB 2.0 — UPDATE NOTES

Included improvements:
- Fullscreen gallery lightbox with previous/next, keyboard controls, Escape and focus restoration.
- Legacy and FiveM event boards are now completed-event archives only, with no upcoming-event sections or filters. Empty states are shown until completed events are added.
- Subtle scroll reveal animations with reduced-motion support.
- Mobile refinements for gallery, event filters and lightbox.
- Open Graph and Twitter metadata, robots directives and skip-to-content navigation.
- Native share support with clipboard fallback.

Deployment: keep the assets folder alongside the HTML files. The HTML references assets/style.css and assets/main.js.

MIDNIGHTCLUB 2.4 — RULES UPDATE

- Kept both rule sets on the same Rules page in clearly separated sections.
- Added separate disciplinary systems for Discord and in-game meets, plus the Discord final notice and car meet enforcement notice.
- Added responsive styling for the disciplinary panels and rule sections.
